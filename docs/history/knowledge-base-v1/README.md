# Base de conhecimento v1 (histórico)

Esta pasta guarda a base de conhecimento usada nas rodadas de avaliação `v1`, `v2` e `cal-*`, até 10/11/2026. Os documentos `01` a `07` eram uma reescrita, com palavras próprias, de páginas públicas para parceiros de uma empresa real de delivery, e o `FONTES.md` lista essas páginas e as lacunas que ficaram sem resposta.

A base foi substituída pela política de parceiros da Rango, empresa de delivery fictícia ([ADR 0018](../../adr/0018-empresa-ficticia-rango.md)), que fica em [`knowledge-base/`](../../../knowledge-base/README.md).

Estes arquivos são histórico: não são ingeridos nem editados. Os links internos do `FONTES.md` apontam para os caminhos antigos e não foram corrigidos.
