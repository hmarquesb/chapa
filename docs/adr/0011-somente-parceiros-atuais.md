# 0011. Restringir o assistente a restaurantes que já são parceiros

- **Status:** Aceito
- **Data:** 2026-11-05

## Contexto

Perguntas de cadastro exigiriam outra base de conhecimento e outro tom.

## Decisão

O público são **só os parceiros atuais**. O cadastro fica fora do escopo, e o perfil do restaurante faz o papel do login.

## Alternativas consideradas

- **Atender também quem quer virar parceiro:** escopo maior, mais documentos e uma avaliação mais fraca.

## Consequências

- A base de conhecimento não tem documento de cadastro.
- Perguntas de cadastro são casos fora do escopo na avaliação.
